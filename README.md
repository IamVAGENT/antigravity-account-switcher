### ⚡ Quick Start

1. **Download or clone** into your Rainmeter skins directory:
   ```text
   Documents\Rainmeter\Skins\Antigravity-Switcher
   ```
2. Open **Rainmeter** &rarr; find `Antigravity-Switcher` &rarr; click **Load**.

---

### 🕹️ How to Use

| Action | Description |
| :--- | :--- |
| **First Launch** | Auto-binds your active session to **Slot 1**. |
| **Add Account** | Click **`+ SETUP`** on an empty slot &rarr; sign in &rarr; click **`SYNC STATUS`**. |
| **Switch Account** | Click any configured slot or **`LAUNCH`** to swap instantly. |
| **Reset Slot** | Click **`RESET`** next to any slot to unlink it. |

---

### 📋 Prerequisites

- **[Rainmeter](https://www.rainmeter.net/)** (v4.5 or newer)
- **[Python 3.8+](https://www.python.org/)** *(must be added to `PATH`)*
- **Google Antigravity** *(standard installation)*
